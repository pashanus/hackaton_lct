# Сопроводительная документация

Локальный интерактивный тренажёр переговоров. Версия 0.6.0, состояние на 29 сентября 2026 года. Подготовлено для кейса ОЭЗ ППТ «Алабуга».

## Аудитория и проблема

Начинающим специалистам и руководителям приходится согласовывать сроки, бюджет и объём работы. Прототип даёт возможность попробовать решения до реального разговора, увидеть последствия и сравнить продолжения одной ситуации. Тренер задаёт контекст и ограничения.

Ценность относительно чтения теории - практика с обратной связью и переигрыванием. Это продуктовая гипотеза: интервью с аудиторией и измерение переноса навыка пока не проводились.

## Путь пользователя

Выбор ситуации / бриф / переговоры / предложение / подтверждение / последствия / разбор / новая ветка. Завершённые попытки сохраняются и дают игровой опыт. Из базы знаний можно сразу перейти к практике.

| Раздел | Содержимое |
| --- | --- |
| Тренировки | Поставка, дедлайн проекта и объяснение ошибки «Не та вкладка». |
| Прокачка | История, XP, пять рангов от sub 3 до true adam. |
| База знаний | Три видеопримера, шесть мнемоник с 31 пояснением и кнопками запуска. |

## Граница MVP

Один локальный профиль, два настраиваемых шаблона переговоров и отдельный четырёхходовый кейс. Нет авторизации, многопользовательской серверной БД и генератора произвольных сценариев.

Версия сатирическая: используются ненормативная лексика и мемные материалы. Свободный чат сохраняет выбранный командой формат случайных заготовленных ответов. Это не демонстрация диалога с языковой моделью.

# Запуск за несколько шагов

Нужны Node.js 22 или новее и актуальный Chrome. Установка Node.js: nodejs.org. Для самого приложения не нужны ключи API, Python, Docker и установка npm-пакетов.

## Обычный запуск с сохранением истории

1. Распакуйте 01_ARENA_SOURCE.zip. Откройте терминал внутри папки negotiation-arena, где находится server.mjs. 2. Проверьте Node.js и запустите сервер:

```sh
node --version
node server.mjs
```

3. Откройте http://127.0.0.1:5177/#arena в Chrome. Оставьте терминал работающим. Остановка - Ctrl+C. На Mac также доступен start.command.

Обычный запуск хранит состояние в data/arena.json. После остановки и нового запуска попытки сохраняются. Для резервной копии остановите сервер и скопируйте папку data. В архив сдачи исходная история не входит.

## Чистая репетиция

```sh
node scripts/demo.mjs
```

Откройте http://127.0.0.1:5182/#arena. Каждый запуск создаёт отдельную временную историю; путь выводится в терминале. Перезагрузка страницы историю текущей репетиции сохраняет. Основная data/ не меняется. На Mac есть start-demo.command.

## Если порт занят

| Среда | Команда |
| --- | --- |
| macOS / Linux | ARENA_PORT=5183 node server.mjs |
| PowerShell |  $env:ARENA_PORT="5183"; node server.mjs |

Затем откройте http://127.0.0.1:5183. Адрес 127.0.0.1 доступен только на текущем компьютере; это не публичная ссылка. ARENA_DATA_DIR меняет каталог обычного хранилища, ARENA_DEMO_PORT - порт репетиции.

# Архитектура и логика

Браузер / HTTP API / движок правил / JSON-хранилище. Интерфейс использует HTML, CSS и JavaScript без frontend-фреймворка. Сервер написан на Node.js, производственных npm-зависимостей нет.

| Компонент | Ответственность |
| --- | --- |
| server.mjs | HTTP API, выдача статических файлов, последовательное сохранение состояния. |
| engine.mjs | Поставка и проект: допустимость пакета, реакции, оценка, снимки состояния и ветки. |
| game.mjs | Ресурсы подготовки, прогноз и последствия объявленного сбоя. |
| incident.mjs | Отдельный четырёхходовый сценарий объяснения ошибки. |
| manager-chat.mjs | Выбор готовой реплики и медиа для свободного сообщения. |
| public/ | Интерфейс, расчёт XP, локальные медиа, субтитры и методички. |

## Состояние и ветвление

Новая попытка получает копию настроек. Перед действиями сохраняются снимки. Переигрывание создаёт новую ветку с состоянием перед выбранным ходом; исходная попытка остаётся доступной. Завершённые продолжения можно сравнить.

Запись идёт через временный файл и переименование. Повреждённая база не заменяется молча пустой. Сервер слушает 127.0.0.1; файл данных не выдаётся как статический ресурс. Решение рассчитано на один локальный профиль.

## Диалог и ИИ

Быстрые действия вызывают сценарные ответы. Свободный ввод обрабатывает ограниченный классификатор; видимая реплика выбирается из 10 шуток. Первый такой ответ содержит вложение, последующие - с вероятностью 45%. Содержательная реакция движка доступна в блоке «Условия сценария».

Реальная LLM не подключена. Необязательный адаптер chat-completions переформулирует разрешённые ответы, не управляя числами и оценками; он проверен только на локальном имитаторе. ИИ использовался при разработке.

# Настройки, оценка и опыт

Кабинет тренера: #admin, либо База знаний / «Параметры тренировок». Настройки действуют на новые попытки. Повтор и ветка сохраняют исходные условия.

| Настройка | Что действительно меняется |
| --- | --- |
| Сфера, тема, роль | Текстовый контекст и формулировки внутри выбранного шаблона. |
| Цель собеседника | Приоритет и условия приемлемой сделки. |
| Сложность, тон | Доступность интереса, требования к аргументам, манера ответа движка. |
| Числовые ограничения | Бюджет, срок, аванс или ресурсы команды определяют выполнимость. |

## Разные сценарии

Поставка: цена, день, аванс, частичная отгрузка; после соглашения поставки задерживаются на два дня. Проект: объём, срок и люди; после соглашения теряются два человеко-дня. Эти сбои объявлены в брифе. В обоих делах шесть ходов и один выбранный ресурс. «Не та вкладка»: четыре этапа объяснения и согласования исправлений, отдельные сложность и тон.

## Что означают баллы

В поставке и проекте пять критериев по 0-2: интересы, аргументация, обмен уступками, границы, фиксация. Сумма умножается на 10. В объяснительной пять бинарных критериев по 20. Разбор ссылается на действия и фактические реплики.

Учебная оценка и устойчивость сделки показаны отдельно. Можно получить 100/100 за действия и сорвать срок после сбоя. Повтор одной кнопки сам по себе не наращивает балл. Рубрика не является аттестацией профессиональной компетентности.

## Геймификация

За завершённую попытку от двух ходов: 40 базовых XP, до 50 за критерии, 30 за соглашение и 20 за устойчивость. Ветки считаются отдельными попытками; обновление страницы не выдаёт опыт повторно. Пороги рангов: 0 / 100 / 250 / 450 / 700 XP.

Ресурс может раскрыть интерес, дать резерв или продлить раунд. Он действует после активации; стоимость и эффект показаны в интерфейсе. XP и мемный ранг поощряют практику, но не доказывают рост навыка.

# Живая демонстрация

Запустите чистую репетицию по странице 2. В #admin выберите поставку: цель «Получить предоплату», сложность «Практика», тон «Требовательный», день 10, бюджет 110, аванс до 50%. Поменяйте тему на «Поставка для демонстрации» и сохраните.

Откройте «Просёр поставки». Оставьте выбранным «Расширенный А.Н.А.Л.», но не активируйте его. Для этого маршрута используйте кнопки, сохраняя шесть ходов.

| Ход | Действие |
| --- | --- |
| 1 | «Что вам реально нужно?» |
| 2 | «Достать аргумент» |
| 3 | «Обменяться уступками» |
| 4 | «Показать границы» |
| 5 | 108 тыс. руб., день 10, аванс 30%, две поставки выключены. «Предложить условия». |
| 6 | «Подтвердить соглашение». |

Первый исход: соглашение, 100/100, +120 XP. После задержки вся партия приходит на день 12; целевой срок сорван. Финал «Запахло последствиями».

## Изменить одно решение

Нажмите «Изменить решающий ход»: новая ветка начнётся перед ходом 5. Сохраните цену 108 и аванс 30; поставьте день 8 и включите две поставки 60 + 40. Предложите условия и подтвердите соглашение.

Второй исход: соглашение, 100/100, +140 XP. После задержки партии приходят на дни 10 и 16. Финал «ПЕНИС в порядке». «Сравнить продолжения» покажет одинаковое начало и разные последствия пакетов.

На чистом профиле итог - 260 XP, chad. Покажите #progress, затем #method/perd с пояснениями и кнопкой «Попробовать». В дополнительной новой тренировке можно продемонстрировать текущий мемный чат.

Для проверки влияния администратора после основного маршрута снизьте бюджет до 100 и откройте новую поставку: предложение на 108 нарушит ограничение. Старые ветки сохранят бюджет 110. Отдельный деморолик для живого показа не требуется.

Физически другой компьютер, Windows, Linux и Node.js 22 в этой проверке не использовались. Пользовательское исследование, экспертная проверка рубрики и нагрузочные испытания не проводились.

## Развитие после MVP

Следующие шаги: проверить понятность разбора с пользователями и тренером; оценить перенос приёма на незнакомый кейс; расширить сценарии и содержательный свободный диалог; добавить учётные записи и серверное хранилище под подтверждённый сценарий использования. Рост XP не используется как доказательство учебного эффекта.

## Методы, библиотеки и сервисы

• Node.js: встроенные http, fs, crypto, fetch и node:test; nodejs.org. Для работы текущей версии не нужны внешние сервисы и ключи.

• Сценарии и рубрика авторские. BATNA используется как понятие альтернативы при отсутствии соглашения; ориентир: pon.harvard.edu/tag/batna/. Мнемоники не заявлены научно валидированными методами.

• Материалы: фото и видео предоставлены командой. Часть субтитров подготовлена с локальным Whisper и затем исправлена вручную. Whisper не нужен для запуска.

Для отдельного эксперимента с адаптером предусмотрены ARENA_LLM_URL, ARENA_LLM_MODEL и ARENA_LLM_KEY; пример в .env.example. Реальный сервис и условия его доступа не выбраны. Без URL и модели внешних запросов нет; при подключении провайдер получает контекст и часть диалога.
