АРЕНА ПЕРЕГОВОРОВ - ИНСТРУКЦИЯ ЗАПУСКА

1. Установите Node.js 22 или новее: https://nodejs.org/
2. Распакуйте 01_ARENA_SOURCE.zip.
3. Откройте терминал в папке negotiation-arena (рядом с server.mjs).
4. Выполните:
   node --version
   node server.mjs
5. Откройте Chrome: http://127.0.0.1:5177/#arena

Оставьте терминал открытым. Для остановки нажмите Ctrl+C.
Никаких npm-пакетов, API-ключей, Python или Docker не требуется.

Настройки тренера: http://127.0.0.1:5177/#admin
Обычная история сохраняется в data/arena.json после перезапуска.

Чистая репетиция без сброса основной истории:
   node scripts/demo.mjs
   http://127.0.0.1:5182/#arena
Каждый запуск репетиции начинает отдельный профиль; обычный сервер сохраняет прежний.

Живой показ с точными кнопками и числами: DEMO.md внутри папки проекта.
Полная документация: 02_DOCUMENTATION.pdf, либо docs/DOCUMENTATION.md внутри исходников.

127.0.0.1 - адрес этого компьютера, не публичная ссылка.
Если порт 5177 занят, проверьте, не запущен ли уже сервер.
Другой порт: ARENA_PORT=5183 node server.mjs (macOS/Linux).
PowerShell: $env:ARENA_PORT='5183'; node server.mjs
Затем используйте http://127.0.0.1:5183/#arena.
