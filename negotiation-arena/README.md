# Арена переговоров

Локальный прототип тренажёра переговоров с тремя сценариями, прокачкой и базой знаний. Текущая версия — сатирическая, с ненормативной лексикой и мемными материалами. Актуализировано 29 сентября 2026.

**Полная документация:** [docs/DOCUMENTATION.md](docs/DOCUMENTATION.md). **Живое демо:** [DEMO.md](DEMO.md). **Границы реализации:** [MVP.md](MVP.md).

## Аудитория и задача

Начальный сегмент — начинающие специалисты и руководители, которым нужно согласовывать сроки, объём и условия работы. Тренер или руководитель обучения задаёт контекст. Пользователь пробует решения, получает разбор и переигрывает ситуацию.

Потенциальная ценность относительно чтения теории — практика с последствиями и сравнение альтернативных решений. Это продуктовая гипотеза: интервью с аудиторией и измерение переноса навыка ещё не проводились.

## Запуск на другом компьютере

Нужны **Node.js 22 или новее** и актуальный Chrome. Установка Node.js — с официального сайта https://nodejs.org/. Специализированное оборудование и ключ API не нужны.

1. Распакуйте папку проекта.
2. Откройте терминал **в этой папке**.
3. Проверьте версию и запустите сервер:

```sh
node --version
node server.mjs
```

4. Откройте **http://127.0.0.1:5177/#arena**.
5. Оставьте терминал работающим. Остановка — Ctrl+C.

Устанавливать npm-пакеты и собирать frontend не требуется: приложение использует встроенные модули Node.js. Зависимостей npm нет, поэтому lockfile не нужен. Все медиа и шрифты, необходимые для показа, доступны локально; внешний LLM по умолчанию не подключается.

На Mac можно открыть `start.command` двойным кликом. Он использует локальный Node.js или установленный runtime Codex; на чужом компьютере достаточно обычной установки Node.js. Если запуск кликом недоступен, команда `node server.mjs` остаётся основным способом.

Сервер слушает **только 127.0.0.1**. Это адрес текущего компьютера, не публичный сайт; телефон не подключится к ноутбуку по этой ссылке. При занятом порте сначала проверьте, не работает ли уже сервер. Альтернативный порт:

```sh
# macOS / Linux
ARENA_PORT=5183 node server.mjs
```

```powershell
# Windows PowerShell
$env:ARENA_PORT='5183'
node server.mjs
```

После смены порта используйте соответствующий адрес в браузере.

## Репетиция без изменения основной истории

Mac: `start-demo.command`. На любой поддерживаемой платформе:

```sh
node scripts/demo.mjs
```

Адрес — **http://127.0.0.1:5182/#arena**. Каждый запуск создаёт отдельное временное хранилище с исходными настройками и пустой историей. Путь выводится в терминале. Перезагрузка страницы сохраняет попытки в работающей репетиции; повторный запуск создаёт новый профиль. Основная папка `data/` не затрагивается. `ARENA_DEMO_PORT` позволяет изменить порт репетиции.

## Что есть в интерфейсе

### Тренировки

- **«Просёр поставки»** — цена, срок, аванс и частичная поставка. После соглашения поставки задерживаются на два дня; этот риск известен заранее.
- **«Ларпинг дедлайна»** — объём релиза, срок и дополнительные люди. После соглашения команда теряет два человеко-дня.
- **«Не та вкладка»** — четыре этапа объяснения ошибки и согласования плана исправления, с готовыми вариантами ответов.

В первых двух делах: шесть ходов на обсуждение, один ресурс подготовки, точная карточка предложения, прогноз последствий, отдельное подтверждение, разбор и переигрывание выбранного хода. Согласованный последним ходом пакет можно подтвердить дополнительным ходом. Ресурс начинает действовать после его активации.

### Прокачка

История попыток и ранги **sub 3 → normie → chad → gigachad → true adam**. Опыт за завершённую попытку от двух ходов: 40 базовых XP, до 50 за учебные критерии, 30 за соглашение, 20 за устойчивую сделку. Повторная ветка — новая попытка. Перезагрузка страницы не выдаёт XP повторно. Ранг — игровая механика, не аттестация навыка.

### База знаний

Три локальных примера «как не надо»; у двух есть русские субтитры. Шесть авторских мнемоник: расшифровки и 31 пояснение к пунктам, короткие страницы с примером и одной кнопкой «Попробовать». Есть гайд показа. «Антиприёмы» удалены.

## Настройки тренера

База знаний → «Параметры тренировок» внизу, либо `#admin`.

| Настройка | Реальное влияние |
|---|---|
| Сфера, тема, роль | Текстовый контекст и формулировки; не создают новый тип экономики кейса |
| Цель собеседника | Приоритет и условия приемлемого предложения |
| Сложность | Доступность интереса и требования к обоснованию |
| Тон | Манера ответа движка |
| Бюджет, срок, аванс / люди | Допустимость и выполнимость предложения |

Настройки действуют на новые попытки. Повтор и ветка сохраняют конфигурацию исходной попытки. Произвольного генератора сценариев нет; доступны два параметризованных шаблона. В третьем кейсе настраиваются сложность и тон.

## Мемный чат и границы ИИ

В поставке и проекте свободное сообщение обрабатывается ограниченным классификатором правил. Видимый ответ персонажа выбирается из **10 заранее заданных шуток**; до исчерпания набора они не повторяются. Первый такой ответ обязательно содержит медиа, последующие — с вероятностью 45%. Новый набор: **шесть фото и один ролик**. Старые вложения продолжают отображаться в сохранённых диалогах.

Содержательная реакция движка раскрывается под «Условия сценария». Быстрые кнопки действий отвечают по контексту. Точные числа сделки задаются в карточке предложения. Мемные ответы не генерируются LLM и не доказывают понимание произвольного текста. В этой сборке переключателя в учебный чат нет — текущий формат сохранён по решению команды.

Есть необязательный адаптер chat-completions API: он переформулирует разрешённую реплику, не управляет условиями и баллами. Игровые дела работают автономно; реальный провайдер не подключён и с ним интеграция не проверялась. Проверки адаптера используют локальный имитатор. В свободном мемном чате применяется заготовленный ответ, а не вызов этого адаптера.

Для отдельного эксперимента с адаптером предусмотрен `.env.example`. `start.command` читает `.env`, если он существует; при запуске вручную можно использовать `node --env-file=.env server.mjs`. Переменные: `ARENA_LLM_URL`, `ARENA_LLM_MODEL`, `ARENA_LLM_KEY`. Без URL и модели внешних запросов нет. При подключении провайдер получает контекст и часть диалога; настройки доступа задаются отдельно. Эти параметры не нужны для защиты текущей версии.

ИИ применялся при разработке. Метод оценки написан для прототипа и не проходил экспертной валидации. Авторские аббревиатуры не объявляются научными методами.

## Оценка и повтор

В двух базовых кейсах пять критериев по 0–2: интересы, аргументация, обмен уступками, границы, фиксация. Сумма умножается на 10. Оцениваются события движка и условия пакета; в разборе используются фактические реплики. Повтор одной кнопки сам по себе не наращивает балл. В третьем кейсе пять бинарных критериев по 20 баллов.

Отдельно показаны исход переговоров и устойчивость сделки к заранее объявленному сбою. **100/100 за приёмы совместимы с плохим планом поставки** — это намеренное разделение оценок.

Перед ходами сохраняются снимки. Переигрывание создаёт новую ветку, исходная попытка остаётся доступной. После завершения обеих веток есть сравнение условий, исходов и критериев. Для старых попыток без снимков доступен повтор с начала. Повтор знакомого кейса не доказывает перенос навыка на новые ситуации.

## Архитектура и хранение

```text
Браузер → HTTP API Node.js → правила сценария → JSON-файл
                              ↓
                    последствия сделки и разбор
```

| Файл | Роль |
|---|---|
| `server.mjs` | HTTP API, статические файлы, последовательная запись состояния |
| `engine.mjs` | Два сценария, условия сделки, действия, рубрика и ветки |
| `game.mjs` | Ресурсы, прогноз и проверка последствий |
| `incident.mjs` | Четырёхходовая объяснительная |
| `manager-chat.mjs` | Выбор готовой реплики и вложения |
| `public/` | HTML/CSS/JS, локальные фото, видео и субтитры |
| `public/progression.js` | Расчёт XP и рангов |
| `scripts/demo.mjs` | Изолированная репетиция |

Обычная история хранится в `data/arena.json` и восстанавливается после перезапуска. Запись выполняется последовательно через временный файл и переименование; повреждённое хранилище не заменяется молча пустым. Для копии истории остановите сервер и скопируйте `data/`. `ARENA_DATA_DIR` задаёт другой каталог.

Один локальный профиль, без авторизации и разделения пользователей. Хранилище не отдаётся как статический файл; API предназначен для локального приложения. `show.mjs` и старые UI-модули оставлены для совместимости прежних данных, не являются отдельными разделами текущего продукта.

## Проверки

```sh
npm test
npm run check
```

Тесты используют `node:test`, временные хранилища и локальные HTTP-порты; внешняя сеть не нужна. Результаты — [VALIDATION.md](VALIDATION.md). Проверка в чистой распакованной папке на текущем Mac не заменяет испытание на физически другом компьютере.

## Методы и материалы

- Node.js — https://nodejs.org/ ; встроенные HTTP, fs, crypto, fetch, node:test.
- HTML, CSS, JavaScript без frontend-фреймворка и npm-зависимостей.
- BATNA — концепция альтернативы при отсутствии соглашения; ориентир: https://www.pon.harvard.edu/tag/batna/ . Сценарии и учебная рубрика авторские.
- Требования — «9. ОЭЗ ППТ Алабуга.pdf», разделы 2–5, 7–8.
- Фото и видео предоставлены пользователем; названия внутри `public/media-catalog.js`. Для подготовки части субтитров ранее использовалось локальное распознавание Whisper, затем ручная правка; первые две фразы тёмного ролика уточнил пользователь. Для работы приложения Whisper не нужен.
